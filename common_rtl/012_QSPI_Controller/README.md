# QSPI Controller

## English

This package contains the current QSPI controller/target Hardware Design Specification (HDS), its CSR workbook, the generated RTL, diagrams, waveforms, and implementation notes. `VLSIT_QSPI_CONTROLLER_HDS.md` is the normative design contract. Previous drafts and source-IP analyses are retained under `archive/` and `research/` and do not override the current HDS.

### Current implementation baseline

- Standard SPI controller and target modes share the external data pads and operate mutually exclusively. Dual, Quad, and QPI 4-4-4 formats are controller-only.
- The SoC configures the IP through APB4 CSR and FIFO windows. The read-only XIP window is an AXI4 subordinate interface.
- The generated CSR is APB-clocked. Controller serial, AXI XIP, target sample, and target shift timing use their specified independent domains.
- Indirect command format is selected with `qspi_cmd.format`; XIP format is selected with `qspi_xip_cfg.format`. The unused `qspi_ctrl` format bits are reserved. Event crossings use shared `m_vlsit_event_sync` through the QSPI compatibility wrapper.

### Cấu hình triển khai hiện hành

- Standard SPI hỗ trợ controller và target; hai vai trò dùng chung chân dữ liệu và không hoạt động đồng thời. Dual, Quad và QPI 4-4-4 chỉ dùng ở controller.
- SoC cấu hình IP qua APB4 CSR và FIFO window. Cửa sổ XIP chỉ đọc sử dụng AXI4 subordinate.
- CSR chạy theo clock APB. Clock controller serial, AXI XIP, target sample và target shift là các miền riêng như mô tả trong HDS.
- Lệnh gián tiếp chọn format bằng `qspi_cmd.format`; XIP chọn format bằng `qspi_xip_cfg.format`. Các bit format không dùng trong `qspi_ctrl` đã được reserve.
