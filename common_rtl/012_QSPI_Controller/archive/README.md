# QSPI archive

## English

`../VLSIT_QSPI_CONTROLLER_HDS.md` is the current normative specification. The files in this folder are retained for history and must not be used as the active design contract. `spec_revisions/` contains superseded HDS drafts. `legacy_qspi_dual_quad_ip_spec/` contains the earlier standalone QSPI specification package and its historical collateral. `legacy_diagrams/` contains diagrams retained from that package.

The revision drafts link to the canonical diagrams, waveforms, and CSR workbook in the package root so the historical text remains readable after reorganization.

## Tiếng Việt

`../VLSIT_QSPI_CONTROLLER_HDS.md` là đặc tả hiện hành có giá trị chuẩn. Các tài liệu trong thư mục này chỉ lưu lịch sử, không dùng làm hợp đồng thiết kế hiện tại. `spec_revisions/` chứa các bản HDS đã được thay thế. `legacy_qspi_dual_quad_ip_spec/` chứa gói đặc tả QSPI độc lập trước đây và tài liệu lịch sử đi kèm. `legacy_diagrams/` chứa sơ đồ lưu từ gói cũ.

Các bản đặc tả cũ liên kết tới sơ đồ, waveform và workbook CSR chuẩn ở thư mục package để tiếp tục đọc được sau khi sắp xếp.
