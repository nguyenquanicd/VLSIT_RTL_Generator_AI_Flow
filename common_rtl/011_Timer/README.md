# Configurable Multi-Channel Timer IP

This folder contains the current Timer hardware design specification and its CSR source workbook. The Timer shares one counter across a statically selected 1–8 channel set (default 4), supports 32-bit or 64-bit timing values (default 32), and uses a fixed 16-bit prescaler. The 64-bit counter uses a coherent low-word-then-high-word read sequence. The design scope includes input capture, output compare, edge-aligned PWM, paired PWM-input measurement, one-pulse operation, capture timeout, APB4 programming, aggregated interrupts, and DMA-330 request/data-stream behavior.

## Current design baseline

- `PARA_CAPTURE_COUNT` and `PARA_OUTPUT_COUNT`: 1–8 each, default 4 (pin bus widths of `i_capture_ch` and `o_timer_ch`).
- `PARA_COUNTER_WIDTH`: 32 or 64, default 32; all timing quantities use this width except the 16-bit prescaler.
- `PARA_ASYNC`: default 0; synchronous mode requires APB and Timer clocks to use the same physical net. Value 1 selects asynchronous APB/Timer clock crossing.
- APB4 control/status path: 32-bit data, 16-bit local address.
- Capture: one two-stage synchronizer/filter per input and a four-entry timestamp FIFO per implemented channel.
- DMA: separate capture and compare/update request groups; one to four tagged records per independent programmed burst.
- DMA APB ports: capture stream read at 0x0200; compare/update stream write at 0x0204. Records remain reserved/staged until matching burst-complete acknowledgement.
- Output: compare, PWM, and independent one-pulse operation with boundary-committed preload values.

The canonical ASYNC_CSR sheet is `m_timer_CSR_async_v0.19.xlsx`. Timer functional RTL remains in `rtl/`; the DMA interface is two 4-phase level req/ack pairs (capture and compare/update) with recovery through the self-clearing `cap_clr`/`cmp_clr` CSR bits; there is no DMA-330 flush. The separate `rtl_v2/` set refreshes the generated CSR with APB-CSR-Generator v3.3 and passes rule check (0 errors/149 warnings) and Verilator lint (0 errors/43 warnings). Full Timer functional simulation was not rerun on `rtl_v2/`. The earlier `rtl/` set had 12 rule errors; both source sets are retained for review. Local DMA-330 excerpts in `reference/md_doc/` remain informational and excluded from version control because redistribution is forbidden. WF-006/WF-007 cover req/ack and recovery; WF-012/WF-013 retain their approved timing details.
