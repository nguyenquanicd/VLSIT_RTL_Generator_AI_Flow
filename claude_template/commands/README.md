# Command prompt templates

**VI:** Các file Markdown là mẫu cho 10 Claude Code command. `/code_coverage` đo code coverage sau verification baseline và hỗ trợ đóng gap bằng testcase được lưu cùng Makefile tái chạy. Khi sửa một command, đối chiếu bản đang dùng trong .claude/commands để giữ nội dung đồng bộ.

**EN:** These Markdown files are templates for 10 Claude Code commands. `/code_coverage` measures RTL code coverage after baseline verification and closes eligible gaps with saved tests and a reproducible Makefile. When editing a command, compare it with the active copy in .claude/commands to keep both aligned.
