# Flow JSON Schemas

**VI:** Các JSON Schema mô tả structured spec, final config, verification contract, RTM và verification report. Contract lưu golden-source revision, interface/oracle đã duyệt; RTM sign-off truy vết về spec/standard, không bắt buộc RTL tag.

**EN:** These JSON Schemas define the structured specification, final configuration, verification contract, RTM, and verification report. The contract locks golden-source revisions and the reviewed interface/oracle; RTM sign-off traces to specification/standards and does not require RTL tags.
