# RTL flow maintainer | Skill bảo trì RTL flow

**EN:** Use this skill to adapt Claude Code phase commands to another IP and maintain their JSON schemas. The active commands remain in `.claude/commands/`; this directory contains the maintenance instructions and shared references.

**VI:** Dùng skill này để điều chỉnh command Claude Code cho IP khác và duy trì JSON Schema. Command đang hoạt động vẫn nằm trong `.claude/commands/`; thư mục này chứa hướng dẫn bảo trì và tài liệu tham chiếu dùng chung.
