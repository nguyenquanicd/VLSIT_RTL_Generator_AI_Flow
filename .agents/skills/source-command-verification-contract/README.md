# Verification contract skill

**VI:** Tạo và review hợp đồng verification từ specification, cấu hình và phiên bản chuẩn giao thức đã chọn. Hợp đồng được chốt trước khi sinh RTL.

**EN:** Creates and reviews a verification contract from the specification, configuration, and selected protocol-standard revisions. The contract is approved before RTL generation.
