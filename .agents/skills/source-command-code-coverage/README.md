# RTL code-coverage skill

**VI:** Đo code coverage từ regression đã chạy, cho người dùng chọn metric và ngưỡng, rồi bổ sung testcase có thể tái chạy để đóng các gap phù hợp với specification. Mọi lệnh test và coverage đi qua một Makefile duy nhất.

**EN:** Measures code coverage from the verification regression, lets the user choose a metric and threshold, then adds reproducible specification-based tests for eligible gaps. All test and coverage commands run through one Makefile.
