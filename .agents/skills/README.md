# VLSIT workflow skills

**VI:** Thư mục này có 11 skill cho các phase chính, skill `source-command-rtl-style-converter` cho RTL có sẵn và `rtl-hierarchy-diagram` để phân tích hierarchy. Sau Gate 2, `/verification_contract` chốt baseline verification từ spec/config/chuẩn; nhánh RTL và nhánh verification không dùng artifact của nhau làm nguồn hành vi. Bộ chuyển style có thể thay `/rtl_generator` khi user cung cấp RTL gốc, và báo bug gốc riêng bằng tiếng Anh–Việt. Gọi skill theo tên thư mục. Quy tắc đặt câu hỏi nằm tại `decision_prompt_standard.md`. Khi user không cung cấp RTL rule, dùng `../../spec_template/VLSIT_RTL_Design_Rule.md`. Script hỗ trợ nằm trong `../../scripts/`; chính sách đề xuất update skill tại `../skill_maintenance.md`.

**EN:** This directory contains 11 main workflow-phase skills, `source-command-rtl-style-converter` for existing RTL, and `rtl-hierarchy-diagram` for hierarchy analysis. After Gate 2, `/verification_contract` freezes a spec/config/standard-based verification baseline; the RTL and verification branches do not use each other's artifacts as behavioral sources. The style converter may replace `/rtl_generator` when the user supplies original RTL and reports original bugs separately in English and Vietnamese. Invoke a skill by its folder name. `decision_prompt_standard.md` defines how skills present analysis and options. With no user RTL rule, use `../../spec_template/VLSIT_RTL_Design_Rule.md`. Helper scripts are in `../../scripts/`; skill-update approval is governed by `../skill_maintenance.md`.
