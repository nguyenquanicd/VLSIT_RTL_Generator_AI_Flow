# VLSIT workflow skills

**VI:** Thư mục này có 11 skill cho các phase của flow và skill `rtl-hierarchy-diagram` để phân tích hierarchy. Sau Gate 2, `/verification_contract` chốt baseline verification từ spec/config/chuẩn trước khi sinh RTL; nhánh RTL và nhánh verification dùng chung baseline nhưng không đọc artifact sinh ra của nhau. `source-command-code-coverage` đo code coverage RTL sau verification baseline. Gọi skill theo tên thư mục. Quy tắc đặt câu hỏi nằm tại `decision_prompt_standard.md`. Khi user không cung cấp RTL rule, RTL Generator dùng `../../spec_template/VLSIT_RTL_Design_Rule.md`. Script hỗ trợ nằm trong `../../scripts/`; chính sách đề xuất update skill tại `../skill_maintenance.md`.

**EN:** This directory contains 11 workflow-phase skills and `rtl-hierarchy-diagram` for hierarchy analysis. After Gate 2, `/verification_contract` freezes a spec/config/standard-based verification baseline before RTL generation; RTL and verification branches share the approved baseline but do not consume each other's generated artifacts. `source-command-code-coverage` measures RTL code coverage after baseline verification. Invoke a skill by its folder name. `decision_prompt_standard.md` defines how skills present analysis and options. If no RTL rule is supplied, RTL Generator uses `../../spec_template/VLSIT_RTL_Design_Rule.md`. Helper scripts are in `../../scripts/`; skill-update approval is governed by `../skill_maintenance.md`.
