# VLSIT workflow skills

**VI:** Thư mục này có 9 skill cho các phase của flow và skill `rtl-hierarchy-diagram` để phân tích hierarchy. Gọi skill theo tên thư mục. Khi không có rule file do người dùng cung cấp, RTL Generator dùng mặc định `../../spec_template/VLSIT_RTL_Design_Rule.md`. Các script hỗ trợ lập chỉ mục artifact và rút gọn log nằm trong `../../scripts/`. Quy trình đề xuất cải tiến và yêu cầu xác nhận được mô tả tại `../skill_maintenance.md`.

**EN:** This directory contains 9 workflow-phase skills and `rtl-hierarchy-diagram` for hierarchy analysis. Invoke a skill by its folder name. When the user provides no RTL rule file, RTL Generator uses `../../spec_template/VLSIT_RTL_Design_Rule.md` by default. Artifact indexing and bounded log summaries are available in `../../scripts/`. The improvement proposal and user-approval policy is defined in `../skill_maintenance.md`.
