# Verification skill

**VI:** Chạy simulation và mutation check khi công cụ sẵn có, đo code-coverage baseline trước Gate 5, rồi cập nhật RTM và verification report. Ngưỡng coverage là tùy chọn; mọi lệnh chạy qua Makefile của design.

**EN:** Runs simulation and mutation checks, measures code-coverage baseline before Gate 5, then updates the RTM and verification report. The coverage target is optional; all EDA run commands use the design Makefile.
